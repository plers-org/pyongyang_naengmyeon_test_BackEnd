D-2

4축 점수가 15곳에서 결측

근거 보강 필요

육향·감칠맛·메밀향·산미 중 일부가 빈 문자열인 가게가 15곳이며, review_status = needs_more_evidence인 15곳과 정확히 일치합니다. 능라도(강남점)·을밀대(본점)·필동면옥 등이 여기 속합니다.

영향 적재 코드가 필터링보다 먼저 모든 행을 float()으로 변환해, 빈 값에서 ValueError로 죽습니다. 필터를 아무리 완화해도 마이그레이션 자체가 실패했습니다.

영향 DB 컬럼은 준비됐으나 값이 전부 null이라 결과 화면의 "평냉 지도 보기" 버튼을 띄울 수 없습니다.

unknown을 후보에서 배제하지 않음

적용됨

필터를 != "open"이면 제외에서 closed만 제외로 완화했습니다. unknown은 "폐업했다는 근거가 없는 상태"이지 폐업이 아니라는 해석입니다. 이것만으로 후보가 0곳 → 17곳이 됐습니다.

  • 위치: services/recommendation_service.py:127-130
  • 회귀 방지 테스트로 unknown은 포함, closed는 제외를 고정해 뒀습니다.
  • 주의 — 폐업한 가게가 추천될 수 있습니다. D-1이 채워질 때까지 감수하는 리스크입니다.
해제 조건 영업 상태가 실제로 채워지면 필터를 open 기준으로 되돌릴지 팀에서 결정.
